# كيدي ستور — KD STORE

**منصة خدمات السوشيال ميديا والاشتراكات الرقمية**

موقع متكامل وسريع لعرض وبيع خدمات الدعم الرقمي واشتراكات الذكاء الاصطناعي (Google Gemini Pro) بأحدث تقنيات التصميم والتجاوب مع جميع الأجهزة.

---

## 🌟 الميزات الرئيسية

- **تصميم عصري وسريع (Neon & Glassmorphism):** واجهة مستخدم مبتكرة تدعم الوضع الداكن وتجاوب كامل مع الهواتف الذكية.
- **تصفية فلترة ذكية:** تصفية وتجميع الخدمات لحرص العميل وعدم التشتت (خيارات بضمان وبدون ضمان).
- **حساب تلقائي وتحويل العملات:** دعم الجنيه السوداني (SDG) والدولار الأمريكية (USD) مع تحويل مباشر.
- **ربط أوتوماتيكي مع الواتساب:** إنشاء طلبات محددة التفاصيل وإرسالها بنقرة واحدة عبر WhatsApp.
- **نظام تتبع الطلبات:** إمكانية الاستعلام المباشر وتوجيه العملاء للدعم الفني.
- **شريط إعلانات ديناميكي:** شريط تنبيهات علوي متجدد للخصومات والعروض.

---

## 🛠️ التقنيات المستخدمة

- **HTML5 / CSS3 / JavaScript (ES6+)**
- **FontAwesome 6** للأيقونات العصرية
- **Node.js Express Server** للاستضافة والتأكد من استقرار الخدمة

---

## 🚀 التشغيل المحلي

```bash
# تشغيل السيرفر المحلي
node server.js
```

ثم افتح المتصفح على `http://localhost:3000`.
